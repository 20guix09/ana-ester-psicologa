# Ana Ester — site completo

Arquivos da última versão do site, com logo AE, favicon circular, fotos aprimoradas, animações, máscara de telefone e seleções personalizadas.

## Visualizar
Abra dist/index.html no navegador. Para publicar, envie a pasta inteira para seu repositório GitHub.

## Vercel
Importe o repositório. Escolha o framework Other, mantenha os comandos de build e instalação vazios e use dist como diretório de saída. A configuração vercel.json já está incluída. Nome sugerido do projeto: ana-esther-psicologa.

## Ativar o agendamento por e-mail
Em dist/config.js, preencha formSubmitEmail com o e-mail confirmado da psicóloga. Publique a alteração. Faça um envio de teste autorizado e confirme a ativação no e-mail enviado pelo FormSubmit. Sem e-mail configurado, o formulário não envia solicitações; os contatos de WhatsApp e Instagram continuam disponíveis.

Não é necessário instalar dependências. Mantenha os caminhos de arquivos e a pasta assets ao publicar.
